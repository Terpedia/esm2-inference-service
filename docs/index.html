API

One request. Auditable output.

curl -X POST "$SERVICE_URL/v1/embeddings" \
  -H "Authorization: Bearer $(gcloud auth print-identity-token)" \
  -H "Content-Type: application/json" \
  -d '{"request_id":"terpene-synthase-17","sequences":["MKTIIALSYIFCLVFAD"]}'

Responses include the embedding, a SHA-256 of the input sequence, batch telemetry, pooling method, model revision, and checkpoint provenance.

DEPLOYMENT

GPU when needed. Zero when idle.

Client→Cloud Run→Dynamic batcher→NVIDIA L4

The supplied Cloud Run configuration uses one L4 per instance, instance-based billing, private IAM access, bounded concurrency, and minimum instances set to zero. First-request latency includes container and model initialization.

BENCHMARK

Reproducible, never imagined.

The benchmark records hardware, software versions, model revision, checkpoint digest, batch shape, latency distribution, and residue throughput. Published numbers are local measurements only; no L4 performance is claimed until the cloud benchmark is actually run.
